Game carts
==========

Put your own game files here, one folder per console:

  nes/roms     .nes files
  snes/roms    .sfc or .smc files (not zipped)
  gen/roms     .md, .gen or .smd files (Sega Genesis / Mega Drive), also .sms (Master System) and .gg (Game Gear)
  neo/roms     Neo Geo games as .zip (for example mslug3.zip) AND the BIOS file neogeo.zip in the same folder (arcade cabinet)
  sgb/roms     .gb, .gbc or .gba files (Game Boy, Game Boy Color and Game Boy Advance)
  gc/roms      GameCube discs: .iso, .gcm, .rvz, .gcz or .ciso (the GameCube cart; PC only, needs a graphics
               card with OpenGL 3.3). Memory cards are kept in gc/saves/User.
               Pad: sticks and triggers are analog. Gamepad: RB = Z, triggers = L / R.
               VR: triggers = L / R, click the right stick = Z. Keyboard: arrows = stick, W = Z, Q = L, R = R.

Battery saves are written to the saves folder next to roms.
In the room: put a cart in the console, switch it on, pick up a controller from the rug and choose a game.
Hold START + SELECT for a second to go back to the game list.
If something does not start, look at emulator.log in this folder.
